# 주동목 | 영어 문장 조립 학습 서비스

**주어·동사부터 시작해 영어 문장을 직접 완성하는 학습 웹앱**입니다. 영어 초급 학습자, 특히 50~60대 학습자도 복잡한 메뉴 없이 짧게 연습할 수 있도록 설계했습니다.

**[▶ 주동목 직접 사용하기](https://splendorous-mochi-346e26.netlify.app/)**

## 문제와 해결 방식

영어 문법을 배웠어도 실제 문장을 직접 만드는 데 어려움을 느끼는 학습자를 위해, 문장 구성 요소를 한 번에 하나씩 선택하도록 돕습니다.

1. 한국어 문장 확인
2. 주어 → 동사 → 필요한 문장 성분 선택
3. 시간·장소 등 추가 정보로 문장 확장
4. 완성 문장 확인과 말하기 복습

현재는 **7일 커리큘럼**으로, 하루에 **be동사 문장 1개 + 일반동사 문장 1개**를 연습합니다.

## 지금 구현된 기능

- 회원가입 없는 익명 학습 시작 (Supabase Auth)
- 학습 진도 저장 및 초기화 (기기 로컬 저장)
- 학습 완료, 오답 수, 연습 시작·진행·완료 등 온라인 기록 (Supabase PostgreSQL)
- 사용자 의견/난이도 평가 수집
- 운영자 인증 및 Row Level Security(RLS)로 보호된 관리자 대시보드
- GitHub `main` 브랜치 변경 시 Netlify 자동 배포

> **개발 중**인 서비스입니다. 현재 학습 데이터로 학습 효과가 입증되었다고 주장하지 않습니다. 방문자 수, 재방문율 등 모든 지표가 자동 수집되는 것은 아닙니다.

## 기술 구성

| 영역 | 기술 | 역할 |
|---|---|---|
| 화면·학습 로직 | HTML / CSS / JavaScript | 모바일 우선 사용자 경험 |
| 배포 | Netlify | 공개 웹서비스, GitHub 자동 배포 |

| 알림 (2026-11-14 실기기 테스트 완료) | OneSignal + Supabase Edge Functions | 관리자 푸시 알림 |

학습 흐름은 튜토리얼 3단계 → 사용법 안내 → 홈 → 초급 7일 코스(하루 8개 활동) → 복습. 영어 문장 듣기는 사용자가 버튼을 눌러야만 재생됩니다.

**업데이트 원칙:** URL을 새 버전마다 바꾸지 않고 `preview-v3/index.html`만 수정합니다. 사용자 진도는 안정적인 브라우저 저장 키 `judongmok:learner-progress:v1`에 저장하고, 과거 V2/V3 키에서 자동 이전합니다. 코드 업데이트만으로 학습 기록이 초기화되지 않도록 설계했습니다.

**주의:** 이 기록은 동일한 브라우저 저장소 안에서만 유지됩니다. 카카오톡 내장 브라우저 ↔ 크롬/사파리, 기기 변경 및 브라우저 데이터 삭제 시 자동 동기화되지 않습니다. 서버 계정 기반 동기화는 아직 없습니다. 이전 테스트 모드에서 저장되지 않았던 진도는 복구할 수 없습니다.

기존 정식 서비스 `index.html`(Supabase 관리자·피드백 연동 포함)는 별도이며 이번 변경에서 수정하지 않았습니다. 실제 Netlify 배포 완료 및 사용자 실기기 테스트는 독립 확인이 필요합니다.

## 운영 시 주의사항

- API의 **Publishable key**는 브라우저에서 쓰도록 설계된 공개 키지만, 실제 데이터 보호를 위해 RLS 정책이 필수입니다.
- **DB 비밀번호, Supabase Secret/Service Role 키, Telegram 봇 토큰**은 저장소에 절대 올리지 않습니다.
- `admin/` 페이지의 URL이 공개되어도 관리자 권한이 없는 사람에게 다른 사용자의 데이터가 노출되지 않도록 정책을 유지해야 합니다.
- 실제 학습자 데이터를 GitHub에 업로드하지 않습니다.
- 웹 앱과 앱스토어용 네이티브 앱은 다릅니다. 현재는 설치 가능한 웹앱(PWA)을 목표로 합니다.
- 알림 기능은 2026-11-14에 실기기 작동을 확인했습니다. 향후 운영 중에는 푸시 권한, 웹훅, Edge Function 및 비밀값 설정을 유지·점검해야 합니다.

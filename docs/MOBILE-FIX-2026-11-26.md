# 주동목 V3 모바일 안정화 — 2026-11-26

## 사용자 재현 보고
1. 모바일에서는 성공 폭죽·축하 메시지 등 효과가 정상 표시되지 않거나 UI와 겹침.
2. 모바일에서 정답을 맞힐 때마다 "이 브라우저는 영어 음성 듣기를 지원하지 않아요"라는 경고 팝업 반복.

## 확인한 원인과 조치
- **음성 TTS:** V3 `speak()`이 `SpeechSynthesisUtterance`가 없는 브라우저에서 무조건 `alert`를 띄웠고, 학습 정답 처리 과정에서 자동 호출돼 경고가 반복됨. 이제 자동 호출은 미지원 환경에서 **조용히 건너뜀**. 듣기 버튼을 직접 누른 경우에만 해당 버튼을 `🔇 이 환경에서 듣기 불가`로 변경하고 비활성화. 지원하는 브라우저에서는 기존 TTS 유지. 앱 내장 브라우저에서 실제 TTS 재생을 보장하는 기능은 **미구현**.
- **축하 UI 겹침:** 기존 `celebrate()`가 매번 34~94개 파티클을 뷰포트 전역에 만들고, 동작 줄이기 설정에서는 **화면 중앙 고정 배너**를 만들어 본문과 겹칠 가능성이 있었음. 또 `showToast()`가 고정 위치 안내 배너를 겹쳐 띄웠음.
- **새 보상 방식:** 문장 중간 완료는 기존 피드백 줄의 인라인 성공 텍스트로 대체. 하루·튜토리얼 완료의 폭죽은 기존 **성공 체크 아이콘 내부에 22개 작은 파티클**로 제한하고, 움직임 줄이기 설정에서는 애니메이션을 실행하지 않음. 체크 아이콘·완료 문구는 항상 표시. 고정 팝업 요소 생성하지 않음.
- **휴대폰 완료 화면:** 폭 550px 이하에서 완료 화면을 상단부터 세로로 배치하고 큰 여백·카드 패딩을 줄임. 특히 좁고 높이가 짧은 화면에서 버튼이 겹치지 않고 아래로 스크롤 가능하게 구성.

## 테스트 완료
- V3 JavaScript 구문 검사 성공.
- 모바일 WebView와 유사하게 `speechSynthesis` API를 제공하지 않는 환경을 모의해 튜토리얼 전체 및 **7일×8활동=56활동** 완료 확인.
- 같은 모의 환경에서 **경고창 호출 0회, 본문 위에 올라오는 전역 오버레이 생성 0회** 확인.
- 일반 애니메이션 환경에서는 체크 아이콘에 파티클 생성, 움직임 줄이기 환경에서는 파티클 없이 완료 UI 유지 검증.
- **미검증:** 실제 사용자 휴대폰, 카카오톡·ChatGPT 등 내장 브라우저, Netlify 배포 반영 및 음성 출력 장치. 모의 DOM 검사는 실기기 검증이 아님.

# 주동목 개발 기록 (2026-11-14)

## 문제와 가설

영어 문법을 설명으로는 이해하지만 문장을 직접 구성하기 어려운 초급 학습자, 특히 50~60대 학습자를 위한 서비스다. 주어 → 동사 → 보어/목적어 → 확장 표현의 선택 과정을 통해 문장 구성 감각을 연습하도록 설계했다. 이 방식의 실제 학습 효과는 아직 검증되지 않았다.

## 다음 검증: 1명 → 3~5명

1. 처음에는 지인 1명에게 링크만 보내고 Day 1을 사용하게 한다.
2. 사용법을 과도하게 설명하지 않고, 헷갈렸던 화면과 이유를 편하게 말하도록 요청한다.
3. 관리자 화면에 실제 사용 시도, 완료, 피드백이 반영되는지 비교한다.
4. 발견된 문제가 UI/설명/난이도/기술 오류 중 무엇인지 구분한다.
5. 그 다음 50~60대 학습자 3~5명으로 소규모 테스트를 확장한다.

피드백은 '좋다/나쁘다' 자체보다 '어느 단계에서 왜 막혔는지'가 중요하다. 새로운 기능과 7일 이후 콘텐츠 확장은 그 결과를 본 후 결정한다.

## 아직 남은 운영 과제

- 서로 다른 기기와 브라우저에서 익명 기록이 섞이지 않는지 확인
- 연결 실패 후 재전송/중복 기록 가능성 점검
- 사용자별 학습 결과와 중단 구간 분석 방식을 설계할 필요가 있는지 검토
- 서비스 데이터 보존·삭제 정책 및 운영 오류 대응 절차 확정
- 공개 운영 시 스팸·과도한 트래픽·비용 확인

# 주동목 고정 링크·진도 보존 정책 (2026-11-26)

## 사용자가 공유할 주소

- **고정 학습 주소**: https://splendorous-mochi-346e26.netlify.app/preview-v3/
- 기존에 공유된 `/preview-v2/` 링크는 같은 도메인의 `/preview-v3/`로 자동 이동함. 쿼리와 해시는 보존함.
- 기존 `/preview-v3/` 주소는 앞으로도 그대로 사용. 새 V4, V5 URL을 만들지 않음.
- 정식 운영 앱 `/index.html`은 별도 앱이므로 변경하지 않음.

## 학습 기록 유지

현재는 **동일한 기기·동일한 브라우저(또는 같은 앱 내장 브라우저)**의 `localStorage`를 사용함. 페이지 코드·UI 업데이트는 저장된 기록을 삭제하지 않음.

- 앞으로 변경 금지할 저장 키: `judongmok:learner-progress:v1`
- 이전 V3 키: `judongmok:preview-v3:progress-v1`
- 이전 V2 키: `judongmok:preview-v2:progress-v1`
- 새 코드가 열리면 두 이전 키의 **완료 일차, 복습 문장, 진행 중인 활동과 선택한 단어 수**를 새 키로 복사·병합함.
- 기존 데이터는 삭제하지 않음. 다중 기록이 있을 땐 더 높은 완료 일차 및 활동 진도를 우선하고 복습 기록을 일차별로 합침.
- 이후 저장은 새 키로만 수행. 미래 버전에서도 같은 키와 마이그레이션을 유지해야 함.
- `/preview-v2/` 링크는 V3으로 이동하므로 별도 학습 구현/기록 분기가 생기지 않음.
- 배포 시 `_headers` 설정으로 V2·V3의 HTML은 재검증하도록 하여 오래된 캐시 사용을 줄임. 오프라인에서 오래된 캐시가 보일 가능성은 별도 문제임.

## 기존 공유 파라미터 호환

- 과거 공유했던 `?tutorial=1&demo=1` 링크도 **일반 학습 링크**처럼 작동하고 저장됨. 처음 방문한 경우에만 튜토리얼; 이미 완료했다면 홈으로 이동.
- `?replay=1`은 튜토리얼 재방문용(학습 기록 유지).
- `?test=1&replay=1`은 개발자용 비저장 테스트 모드. 실제 학습자에게 공유하지 않음.
- 과거 `demo=1` 모드에서 **원래 저장되지 않았던 기록은 복구할 수 없음**.

## 한계

**같은 브라우저 안에서 업데이트가 되어도 이어 하기**는 가능하지만, 다른 휴대폰이나 다른 브라우저에서 자동 동기화하는 것은 아님. 카카오톡 내장 브라우저와 크롬/사파리의 저장소는 분리될 수 있음. 브라우저 데이터 삭제·시크릿 모드·저장 공간 제한에서도 기록이 없어질 수 있음.

여러 기기에서 로그인 후 동일한 진도를 보려면 추후 Supabase 등의 서버 DB에 사용자 식별 및 동기화를 구현해야 함. 현재 V3에는 이런 기능이 없으므로 '어디서나 기록 보존'으로 소개해서는 안 됨.
